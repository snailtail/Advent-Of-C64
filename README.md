# Advent of Code in C on a Commodore 64

This is my attempt at solving some of the puzzles from Advent of Code using C running on a Commodore 64.  
Development is done on a modern computer (Macbook Pro from 2012), code is then first tested in the Vice emulator (x64sc), and finally verified to be runnable on the real hardware by transferring binaries and related files using a Pi1541.
